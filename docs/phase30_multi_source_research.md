## Adapter contract to implement before source integration

Use a provider-neutral `EvidenceBatch` with `provider_id`, endpoint/URL, request parameters, license scope, HTTP status, `retrieved_at_utc`, source-published/updated time if present, raw-response SHA-256, competition and season IDs, request count and quota headers. Each `PlayerStat`, `TeamStat`, `Fixture`, `AvailabilityEvent` and `ExpectedMetric` must carry provider entity IDs, canonical TFF IDs **only after reviewed matching**, match/gameweek ID, event date, statistic name/unit/value, field-level provenance, and an explicit `missing_reason` (`not_reported`, `not_covered`, `not_yet_published`, `not_applicable`, `invalid`). Zero remains a value only when the feed documents it as a measured zero.

Crosswalk records should include normalized name, club, date of birth or stable secondary identifier where licensed, match context, match confidence, match method and reviewer. Reject ambiguous names and transfers instead of silently merging. Store raw immutable observations and revisions; never overwrite a prior pre-deadline view. Feature assembly filters both **event date < target kickoff** and **retrieval/published time ≤ prediction cutoff**, and applies a per-field freshness/coverage gate. Pre-match availability and expected-lineup claims need their own observation timestamp; a post-match lineup cannot be backfilled as if it was known before the deadline.

## Feature priority and implementation sequence

1. **Fix provenance and availability semantics first.** Official GW11 history is complete and directly tied to fantasy points; the `DEPARTED` gate discrepancy is concrete. Add an auditable status interpretation test before changing production behavior.
2. **Refresh team xG/shot archive within permitted use.** It already maps all clubs and has 81/81 nonmissing xG, but missing GW10–11 data makes the current xG variants stale. Record retrieval/import and source-match dates independently.
3. **Trial Yuvron with an authorized free key supplied by the user.** Start with `/matches` for GW10–11 and two match details, then 18 squads and a small stratified player sample. Measure TFF ID matching, xG/xA nonnull rates, revisions, response latency and quota headers. Do not scale to a full sweep until the sample passes.
4. **Probe API-Football if a key becomes available.** Confirm league ID/season and endpoint coverage flags first. Its injury and lineup fields may improve availability, but post-match leakage and free quota limit backtesting.
5. **Consider Sportmonks or Stats Perform only after licensing and a sample.** Their documented player xG or minute projections may be useful, but cost, precise Süper Lig coverage, historical point-in-time retrieval and xA/expected-minute semantics remain unresolved.
6. **Backtest before any weight changes.** Compare candidate features on identical pre-deadline snapshots over multiple finalized gameweeks. Report common-player MAE/RMSE, minutes calibration, rank correlation, XI actuals and captain outcomes. No production weight is assigned by this audit.

This sequence ranks verified official minutes/availability and refreshed team xG ahead of unmeasured premium fields. It also makes historical cutoff integrity a condition for any apparent predictive gain.
